# 📒 오늘의 돈 기록장

> 알뜰하게 절약하자! 🌱

개인 개발 프로젝트로 제작한 **웹 기반 가계부 서비스**입니다.  
수입과 지출을 기록하고, 달력과 월별 목록을 통해 소비 내역을 쉽게 확인할 수 있도록 구현했습니다.

## ✨ 주요 기능

### 📅 달력 기반 가계부

메인 페이지에서 전체 달력을 확인할 수 있습니다.

- 날짜별 수입 금액 표시
- 날짜별 지출 금액 표시
- 수입과 지출을 각각 합산하여 표시
- 날짜 클릭 시 해당 날짜가 입력된 가계부 작성 페이지로 이동
- 이전 달 / 다음 달 이동
- 오늘 날짜 표시

### 💰 가계부 입력

수입과 지출을 구분하여 기록할 수 있습니다.

- 수입 / 지출 선택
- 수입 / 지출에 따른 카테고리 선택
- 금액 입력
- 메모 작성
- 날짜 선택
- 달력에서 선택한 날짜 자동 입력

### 📋 가계부 조회

월별 또는 전체 가계부 내역을 확인할 수 있습니다.

- 월별 지출 내역 조회
- 전체 내역 조회
- 수입만 조회
- 지출만 조회
- 카테고리별 지출 합계 확인
- 상세 내역 확인
- 내역 수정
- 내역 삭제

### 📊 월 평균 지출

최근 기간을 선택하여 월 평균 지출을 확인할 수 있습니다.

- 최근 1개월
- 최근 3개월
- 최근 6개월
- 최근 12개월

선택한 기간의 지출을 기준으로 월 평균 지출을 계산합니다.

## 🗄 데이터 구조

가계부 데이터는 다음과 같은 정보를 저장합니다.

| 컬럼 | 설명 |
|---|---|
| id | 가계부 번호 |

## 🔍 구현하면서 고려한 부분

### 날짜 기반 조회

`LocalDate`와 `YearMonth`를 활용하여 월별 시작일과 마지막 날짜를 계산하고 해당 기간의 가계부 데이터를 조회하도록 구현했습니다.

### 달력과 가계부 연동

메인 달력에서 날짜를 클릭하면 선택한 날짜를 URL 파라미터로 전달합니다.

이를 통해 가계부 입력 페이지에서 선택한 날짜가 자동으로 입력되도록 구현했습니다.

### 수입 / 지출 분리

수입과 지출을 `type`으로 구분하여 관리하고 있습니다.

- `INCOME` → 수입
- `EXPENSE` → 지출

이를 기반으로 달력에서 수입과 지출을 각각 합산하여 표시하고, 목록에서도 원하는 유형만 조회할 수 있도록 구현했습니다.

### 예외 처리

존재하지 않는 가계부 ID로 상세 조회나 수정 페이지에 접근하는 경우를 고려하여 조회 결과를 확인하고 적절하게 처리하도록 구현했습니다.

삭제 작업 역시 실제 삭제된 데이터의 개수를 확인하여 삭제 성공 여부를 판단하도록 구성했습니다.
